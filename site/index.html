01 — Why Discodex

A tray icon with
a narrow job.

One small executable reads local session logs, reduces them to a handful of safe fields, and publishes presence. It does not proxy your AI, phone home, or need a login.

Adapters

Presence that describes the work

When a provider keeps a stable local log, Discodex reports the project, stack, current file, activity and phase — not a generic “using an app” status. Elapsed time comes from the task start, not from launch.

02 — How it works

Local logs in.
Presence out.
Nothing else.

Discodex never calls provider APIs and never inspects network traffic. Everything it knows comes from files already on your disk.

No provider API calls No network reads No cloud component
01

Adapters read local sessions

Each provider gets its own adapter for the shape it actually writes — append-only JSONL, rewritten JSON documents, Markdown transcripts, or SQLite databases. The adapter derives project, stack, file, phase and start time.

02

The filter decides what may exist

Events are reduced to a small PresenceSnapshot before anything reaches Discord. Prompts, responses, absolute paths, commands, tool arguments and tool output have no field to travel in.

03

Discord IPC publishes the result

A thin IPC client publishes the activity and keeps it healthy: reconnecting after Discord restarts, refreshing periodically, and clearing presence when you exit or switch it off.

04 — Privacy model

Nothing sensitive leaves the process.

Discord learns that you are building. It does not learn what you asked, what the model answered, or where the files live.

Read the privacy model

May be sent

  • Provider name
  • Workspace folder name
  • Inferred language or framework
  • Current file basename
  • Normalized activity label
  • Phase and task start time
  • Agent role, model, reasoning effort

Never sent

  • Prompts and assistant responses
  • Full file paths
  • Raw shell commands
  • Tool arguments and output
  • Session contents
  • Window titles and browser URLs
  • Account identifiers

Focused-app detection compares executable names and known product names in the active window title, locally. The title is neither stored nor included in presence. Turn the layer off in the tray and rich session tracking keeps working.

05 — Install

Two minutes,
no installer.

01

Download the release

Grab discodex.exe from the latest GitHub release. A single file, nothing bundled around it.

02

Run it

The icon appears in the notification area. Configuration is created on first launch at %APPDATA%\Discodex.

03

Keep Discord running

Presence connects over Discord IPC and reconnects by itself if Discord starts later or restarts.

Requirements: Windows 10 or 11, Discord Desktop. One Discodex process runs per Windows session.

Build from source · PowerShell 
# Rust 1.85+ · Discord Desktop
git clone https://github.com/braces157/discodex.git
cd discodex
cargo test
cargo build --release
# → target\release\discodex.exe

# Optional: your own Discord application ID
$env:DISCODEX_DISCORD_APPLICATION_ID = "YOUR_APPLICATION_ID"
cargo build --release
